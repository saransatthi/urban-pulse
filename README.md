Urban Pulse – Urban Waste Management Analytics

Project Overview

Urban Pulse is a data analytics project focused on analyzing urban service complaints. The project helps understand complaint patterns, agency workload, borough-wise distribution, and complaint resolution performance.

Project Objectives

- Analyze urban service complaints.
- Identify the most common complaint types.
- Understand borough-wise complaint distribution.
- Analyze agency workload.
- Evaluate complaint resolution time.
- Identify monthly complaint trends.
- Build an interactive dashboard using Streamlit.

Dataset

- Dataset: NYC 311 Service Requests
- Records: 100,000 rows
- Columns: 29
- The dataset contains complaint details, agencies, boroughs, status, dates, and geographic coordinates.

Tools and Technologies

- Python
- Pandas
- MySQL
- SQL
- Matplotlib
- Streamlit
- Jupyter Notebook

Project Workflow

1. Data collection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL database creation and data analysis
5. Development of 15 SQL analyst queries
6. KPI calculation
7. Data visualization
8. Interactive Streamlit dashboard development

Dashboard Features

- Total Requests
- Recorded Closure Percentage
- Open Requests
- Median Resolution Hours
- Complaint Type Analysis
- Agency Workload Analysis
- Borough-wise Complaint Analysis
- Monthly Complaint Trend
- Geographic Complaint Concentration Map
- Interactive filters
- Filtered Complaint Records

Project Files

- "app.py" – Streamlit dashboard application
- "urban_pulse_15_queries.sql" – SQL analyst queries
- "README.md" – Project documentation

How to Run the Project

1. Install the required Python libraries.
2. Configure your MySQL database connection.
3. Open the project folder in the terminal.
4. Run the following command:

streamlit run app.py

Project Outcome

The project provides an interactive view of urban service complaints and helps explore complaint patterns, agency workload, geographical distribution, and resolution performance.
